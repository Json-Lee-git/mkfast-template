# 小红书运营系统飞书多维表格字段清单

> 阶段：真实商品验证前。
> 用途：把调研结论转成可直接搭建的无代码表结构。
> 原则：先跑 3 个真实商品，不做自动化开发。

## 1. 使用方式

先建 7 张表：

```text
商品候选库
供应链记录
对标笔记库
内容测试计划
发布与数据回填
复盘动作库
风险与证据库
```

最小流程：

```text
商品候选库 -> 供应链记录 -> 对标笔记库 -> 内容测试计划
-> 发布与数据回填 -> 复盘动作库 -> 风险与证据库
```

第一轮只放 3 个商品。字段宁可少一点，但每天必须回填。

## 2. 商品候选库

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | ---: | --- |
| 商品编号 | 自动编号/文本 | 是 | 例如 P001 |
| 商品名称 | 文本 | 是 | 商品的真实名称 |
| 商品类目 | 单选 | 是 | 家居、个护、食品、母婴、服饰、数码、宠物、礼品、其他 |
| 核心卖点 | 多行文本 | 是 | 一句话写清楚为什么有人买 |
| 目标人群 | 多选 | 是 | 宝妈、学生、上班族、情侣、送礼人群、小户型、精致生活、懒人、其他 |
| 使用场景 | 多选 | 是 | 通勤、宿舍、办公室、厨房、卧室、旅行、节日、收纳、应急、其他 |
| 进货价 | 数字 | 是 | 单件采购成本 |
| 预计售价 | 数字 | 是 | 小红书预期成交价 |
| 毛利率 | 公式 | 是 | `(预计售价 - 进货价) / 预计售价` |
| 物流难度 | 单选 | 是 | 低、中、高 |
| 售后风险 | 单选 | 是 | 低、中、高 |
| 内容可拍性 | 单选 | 是 | 强、中、弱 |
| 小红书匹配度 | 打分 | 是 | 1-5 分 |
| 初筛结论 | 单选 | 是 | 可测、待补证据、暂不测 |
| 负责人 | 人员 | 是 | 谁推进 |
| 备注 | 多行文本 | 否 | 其他判断 |

推荐视图：

- `全部商品`
- `本轮 3 个测试商品`
- `待补证据`
- `暂不测`

| 退换政策 | 多行文本 | 是 | 供应商支持情况 |
| 可否一件代发 | 单选 | 是 | 可以、不可以、不确定 |

## 4. 对标笔记库

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | ---: | --- |
| 关联商品 | 关联记录 | 是 | 每个商品至少 3 条 |

| 对标账号 | 文本 | 是 | 账号名 |

## 5. 内容测试计划

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | ---: | --- |
| 关联商品 | 关联记录 | 是 | 关联商品候选库 |
| 关联对标 | 关联记录 | 是 | 至少关联 1 条对标 |
| 测试编号 | 自动编号/文本 | 是 | 例如 C001 |
| 内容方向 | 单选 | 是 | 痛点、场景、对比、教程、清单、礼物、避坑、开箱、复购 |
| 目标人群 | 单选/多选 | 是 | 与商品候选库一致 |
| 标题草案 | 文本 | 是 | 人工最终确认 |
| 首图方案 | 多行文本 | 是 | 拍什么、放什么字 |
| 正文结构 | 多行文本 | 是 | 开头、过程、证据、行动 |
| 证据素材 | 附件/关联记录 | 否 | 实拍图、订单、对比图、参数 |
| 发布状态 | 单选 | 是 | 待写、待拍、待审、已发、暂停 |
| 预计发布日期 | 日期 | 是 | 计划日期 |
| 风险检查 | 单选 | 是 | 通过、待改、高风险 |
| 修改意见 | 多行文本 | 否 | 发布前修改点 |

每个商品第一轮建议生成 9 条内容方向：

```text
3 个场景 x 3 种表达角度
```

## 9. 第一轮验收口径

7 天后只看 5 个问题：

| 问题 | 通过标准 |
| --- | --- |
| 用户愿不愿意填 | 3 个商品每天都能完成回填 |
| 商品判断是否更清楚 | 至少 1 个商品能明确进入下一轮或放弃 |
| 内容计划是否可执行 | 9 条内容方向里至少 3 条能真实发布或进入待发 |
| 数据是否能指导动作 | 能说清下一步为什么是放大、调整、补证据、暂停或放弃 |
| 系统是否值得开发 | 使用者认为表格比靠脑袋记更清楚 |

不通过也有价值。只要能证明用户不愿填、字段太多、对标难找、供应链无法承接，就应该先改流程，不进入开发。

## 10. 建议的字段删减规则

第一轮出现以下情况，直接删字段：

- 连续 3 天没人填。
- 填了也不影响下一步动作。
- 需要打开 3 个以上后台才能查到。
- 用户无法稳定理解字段含义。
- 字段只是为了“看起来专业”，不是为了决策。

第一轮出现以下情况，保留字段：

- 能帮助判断商品是否继续测。
- 能帮助内容从空写变成有证据。
- 能帮助复盘给出下一步动作。
- 能提前发现合规或供应链风险。
