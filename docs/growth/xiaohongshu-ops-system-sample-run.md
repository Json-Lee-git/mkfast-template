## 1. 为什么要做样本演练

前两份文档已经说明：

- 这套资料背后有一条完整的实物电商操盘链路。
- 产品方向不应是普通 AI 文案工具，而应是选品与内容测试工作台。
- 无代码原型可以先用 8 张表跑起来。

但这些还只是结构判断。真正要验证的是：

1. 一个商品能不能被系统化评分。
2. 对标样本能不能转成内容测试方案。
3. 7 天测试节奏是否足够具体。
4. 数据回来后能否给出下一步动作。

所以这里选 3 个样本做演练。

## 2. 三个样本选择

| 样本 | 代表类型 | 为什么选它 |
| --- | --- | --- |
| 穿衣镜 | 大件垂直单品店 | 客单价过百、月销约 800、利润几十，但涉及物流和退货 |
| 拼豆板 | 低粉垂直单品 | 390 粉丝卖 2.3 万单，适合验证低粉高转化逻辑 |
| 解压/情绪陪伴小物 | 情绪价值商品 | 24 小时加购强，适合验证小红书人群和内容场景 |

这三个样本覆盖了三种不同难点：

- 穿衣镜：履约风险高，但客单和利润更好。
- 拼豆板：履约简单，但容易被比价，需要垂直细分和 SKU 深度。
- 解压小物：情绪驱动强，但规则、虚假承诺和同质化风险更高。

## 3. 样本一：穿衣镜

### 3.1 Product 商品候选

| 字段 | 填写 |
| --- | --- |
| 商品名称 | 穿衣镜 |
| 小红书包装名 | 小户型显大穿衣镜 / 出门前 30 秒检查镜 |
| 当前状态 | 待评估 |
| 类目 | 家居 |
| 选品类型 | 垂直店/单品店；低粉高转化；低成本高毛利 |
| 目标人群 | 租房女生、小户型家庭、穿搭用户、独居用户 |
| 使用场景 | 出门前穿搭检查、卧室/玄关布置、拍穿搭照 |
| 核心痛点 | 房间小、镜子不够高级、穿搭看不全身 |
| 情绪价值 | 生活精致感、房间变好看、自我管理 |
| 节点属性 | 搬家季、毕业租房、开学、换季穿搭 |

### 3.2 对标证据

| 证据 | 判断 |
| --- | --- |
| 月销约 800 | 有持续交易能力 |
| 客单价一百多 | 相比低客单品，利润空间更好 |
| 每单利润几十 | 能承受一定售后和测试成本 |
| 大件但非易耗 | 退货主要看质量、破损、预期管理 |
| 内容以家居/穿搭场景为主 | 可用生活实拍弱化广告感 |

### 3.3 选品评分

| 维度 | 分值 | 评分 | 理由 |
| --- | ---: | ---: | --- |
| 毛利空间 | 15 | 12 | 客单过百，每单利润几十 |
| 低粉验证 | 15 | 10 | 样本显示垂直小店能卖，但需补粉丝数证据 |
| 近期热度 | 15 | 9 | 月销不错，但需补 24h 加购/近期增长 |
| 内容可视化 | 10 | 9 | 镜子非常适合家居和穿搭实拍 |
| 场景强度 | 10 | 8 | 租房、玄关、穿搭、出门前检查都明确 |
| 非标程度 | 10 | 6 | 镜子易比价，但风格、尺寸、场景可差异化 |
| 供应链可行性 | 10 | 6 | 大件发货和破损要核验 |
| 履约风险 | -10 | -7 | 大件、破损、物流、退货成本较高 |
| 规则风险 | -10 | -1 | 常规家居品，规则风险低 |
| 扩展空间 | 5 | 4 | 可扩尺寸、边框、房间场景 |
| 合计 | 100 | 56 | 观察候选，补供应链和近期数据后再测 |

### 3.4 系统结论

穿衣镜不是最适合新手的第一单，因为履约风险高。它更适合：

- 有家居供应链的人。
- 能处理大件售后的人。
- 有拍摄能力的人。
- 想做垂直家居店的人。

系统给出的下一步不是立刻发，而是：

1. 补 2 个供应商报价。
2. 核验破损赔付和退货成本。
3. 找 3 条近期穿衣镜爆款笔记。
4. 先测内容，不急着大量上架。

### 3.5 内容测试包

| 场景 | 标题方向 | 封面方向 | 笔记类型 |
| --- | --- | --- | --- |
| 租房显大 | 小房间放这面镜子，空间像多了 5 平 | 镜子前后对比，卧室角落实拍 | 普通笔记 |
| 出门检查 | 每天出门前 30 秒，全靠它拯救穿搭 | 人站镜前整理衣服，弱商品感 | 商品笔记 |
| 玄关改造 | 玄关空一块，放镜子比柜子更显高级 | 玄关一角，镜子+包+鞋 | 商品笔记 |
| 拍穿搭照 | 不露脸也能拍出全身穿搭 | 镜子视角穿搭照片 | 普通笔记 |
| 小户型布置 | 小户型不要乱买柜子，先留一面镜子 | 房间布局图 + 镜子位置 | 干货笔记 |

### 3.6 7 天测试计划

| 天数 | 动作 |
| --- | --- |
| Day 0 | 补供应链、拍 3 个真实家居场景 |
| Day 1 | 发租房显大、出门检查、玄关改造 3 条 |
| Day 2 | 发拍穿搭、小户型布置、尺寸选择 3 条 |
| Day 3 | 看收藏和评论，重点观察“尺寸/安装/破损”问题 |
| Day 4 | 把评论问题做成 FAQ 笔记 |
| Day 5 | 有加购再发商品笔记变体 |
| Day 6-7 | 如果退货/破损疑虑多，先暂停放大 |

### 3.7 复盘规则

| 数据表现 | 下一步 |
| --- | --- |
| 收藏高、成交低 | 强化尺寸、安装、真实买家场景 |
| 评论问破损 | 补包装、售后、破损赔付说明 |
| 加购高、成交低 | 查价格、运费、安装难度 |
| 成交不错但退货高 | 暂停放大，换供应链 |
| 穿搭场景数据好 | 向穿搭镜/全身镜定位迁移 |

- 可以扩 SKU。
- 适合普通笔记和商品笔记组合。

## 6. 三个样本对比

| 维度 | 穿衣镜 | 拼豆板 | 情绪小物 |
| --- | --- | --- | --- |
| 选品总分 | 56 | 65 | 67 |
| 是否适合新手 | 中低 | 高 | 高 |
| 最大优势 | 客单和利润 | 低粉验证强 | 近期加购强 |
| 最大风险 | 大件履约 | IP/同质化 | 规则和虚假感 |
| 内容难度 | 中 | 低 | 中 |
| 供应链难度 | 高 | 低 | 低 |
| 推荐动作 | 补证据 | 小批量测试 | 小批量测试 |

结论：

- 拼豆板更适合作为系统原型第一个演练样本。
- 情绪小物适合验证小红书内容场景和评论区引导。
- 穿衣镜适合验证系统的风险提示能力，不适合盲目上手。

## 7. 这次演练暴露出的系统需求

### 7.1 评分必须能扣分

如果系统只鼓励“这个品不错”，它会误导用户。穿衣镜就是典型：看起来有利润、有销量，但履约风险很高。系统必须明确扣分。

### 7.2 对标数量要成为硬门槛

拼豆板能进入测试，是因为低粉验证强；穿衣镜要先补对标。系统应该规定：少于 3 条对标证据，不进入内容测试。

### 7.3 内容包必须包含普通笔记

运营技巧样本里反复出现一个点：店铺不能全是商品笔记。系统生成内容计划时，应该强制混入普通笔记、干货、互动、反馈类内容。

### 7.4 复盘不该只看曝光

加购、成交、评论疑虑、退货原因比曝光更接近经营结果。系统里的复盘仪表盘要围绕“下一步动作”设计，而不是围绕漂亮图表。

### 7.5 AI 应该先问问题再生成

AI 不能一上来写标题。它应该先问：

- 这个商品的供应链证据够吗？
- 对标样本够吗？
- 目标人群是谁？
- 最强场景是什么？
- 最大风险是什么？

问完再生成内容，质量会高很多。

## 8. 如果做无代码原型，先跑哪一个

推荐顺序：

1. 拼豆板。
2. 情绪小物。
3. 穿衣镜。

原因：

- 拼豆板履约低风险，最适合验证字段和流程。
- 情绪小物能验证标题、封面、评论区和规则风险。
- 穿衣镜用来测试系统能不能识别“有利润但不适合新手”的商品。

## 9. 下一步可以做什么

下一步不是开发，而是做一份真实的无代码表格模板。模板里先放：

- 3 条商品候选。
- 每个商品 3 条对标。
- 每个商品 9 条内容方案。
- 每个商品 7 天发布计划。
- 每个商品一张数据回填表。

如果这套表格用起来顺，开发时就有非常清楚的产品边界。否则，直接开发会太早。
