## LinkedIn

AI search readiness is not a magic ranking layer. It starts with basic technical access:

- Can search and AI crawlers fetch the public page?
- Does robots.txt block GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, or Google-Extended by accident?
- Does Cloudflare or another WAF challenge the crawler even when robots.txt allows it?
- Is the sitemap discoverable?
- Is there useful machine-readable context such as structured data or LLMs.txt?
