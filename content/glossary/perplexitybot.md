title: PerplexityBot
description: Perplexity AI's web crawler used to index and retrieve web content for real-time AI-powered search and answer generation.
---

**PerplexityBot** is Perplexity AI's web crawler. It indexes web content for Perplexity's AI search product, which generates answers with inline citations.

Perplexity also operates **Perplexity-User** for real-time user-requested page fetches.
