---
title: ClaudeBot
description: Anthropic's web crawler used for training Claude models and retrieving web content for Claude's responses and browsing features.
---

**ClaudeBot** is Anthropic's web crawler for the Claude AI assistant. It reads web content for model training and for real-time browsing when Claude users request current web information.

Anthropic also operates **Claude-SearchBot** specifically for search-related features in Claude.

## Robots.txt example

```
User-agent: ClaudeBot
Allow: /
```
