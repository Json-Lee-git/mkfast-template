---
title: AI Search
description: Search technology that uses large language models to understand queries and generate direct answers from web sources, rather than returning a list of links.
---

**AI search** (also called generative search, answer engine, or LLM-powered search) uses AI models to interpret user intent and synthesize answers from web content. Unlike traditional search engines that return blue links, AI search provides a direct answer — often with citations to the source pages.

## Major AI search platforms

- Google AI Overviews
- ChatGPT with web search
- Perplexity AI
- Microsoft Bing Copilot
- Google Gemini
- Claude with web search

## How it differs from traditional search

| Traditional | AI Search |
|-------------|-----------|
| Returns links | Returns answers |
| Users click to read | Users read the answer |
| Ranking determines traffic | Citation determines visibility |
| Optimize for CTR | Optimize for extractability |
