---
title: Meta Description
description: An HTML meta tag that provides a brief summary of a page's content, often used as the snippet text in search results and as input for AI-generated answers.
---

The **meta description** is set via `<meta name="description" content="...">` in the `<head>` of a web page. While it is not a direct ranking factor for traditional search, it influences click-through rates and is increasingly consumed by AI crawlers as a content summary signal.

## Why it matters for AI search

AI models and crawlers read meta descriptions as a high-signal summary. A well-written meta description helps the AI understand the page's core topic and may influence whether the page is cited. An absent or auto-generated description is a missed opportunity.

## Best practices

- Keep it 120-155 characters
- Include the primary keyword naturally
- Make it a true summary — not a keyword dump
- Every page should have a unique description
- Match the description to the actual page content
